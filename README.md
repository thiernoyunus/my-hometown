A one-page travel site about Guinea: top three activities to do, plus a short bio of your guide, Thierno Younoussa Diallo.

**Live demo:** <https://guineahometownproject.netlify.app>

## Getting started

Install the dependencies and run the project:

```
npm install
npm start
```

## Built with

HTML, CSS and JavaScript, run with [Vite](https://vitejs.dev/) (see the Vite docs to learn more about configuring it).
